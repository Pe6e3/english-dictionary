# English Words Learning App

Приложение для изучения английских слов и фраз с современным интерфейсом и автоматическим переводом.

## Структура проекта

- `server/` - Node.js сервер с SQLite базой данных
- `client/` - Vue 3 клиент (Options API)

## Запуск проекта

### 1. Запуск сервера

```bash
cd server
npm install
npm run dev
```

Сервер будет доступен на http://localhost:3002

### 2. Запуск клиента

В новом терминале:

```bash
cd client
npm install
npm run dev
```

Клиент будет доступен на http://localhost:3000

## Функциональность

- ✅ **Добавление новых английских слов и их переводов**
- ✅ **Добавление английских фраз и их переводов**
- ✅ **Автоматическая проверка существования слов/фраз в базе**
- ✅ **Показ существующих переводов**
- ✅ **🆕 Автоматический перевод через бесплатные API**
- ✅ **Современный и стильный интерфейс**
- ✅ **Адаптивный дизайн для мобильных устройств**

## 🆕 Функция автоперевода

При вводе нового английского слова/фразы:
1. Система проверяет, есть ли оно уже в базе
2. Если слова нет, появляется кнопка "Автоперевод"
3. При нажатии система автоматически получает перевод через бесплатные API
4. **🆕 Если найдено несколько вариантов перевода, показывается выпадающий список для выбора**
5. Пользователь может отредактировать перевод или сразу сохранить
6. **Перевод НЕ сохраняется автоматически** - только после подтверждения пользователем

### 🆕 Выпадающий список вариантов перевода

Когда API возвращает несколько вариантов перевода:
- **Отображается сетка карточек** с каждым вариантом
- **Показывается качество перевода** (если доступно)
- **Указывается источник** перевода (API, создатель)
- **Автоматически выбирается лучший вариант** по качеству
- **Пользователь может кликнуть на любой вариант** для выбора
- **Выбранный перевод заполняется в поле** для дальнейшего редактирования

### 🆕 Автоматический перевод при вводе

- **Автоматический запрос перевода** через 0.7 секунды после остановки ввода
- **Антидребезг** предотвращает лишние запросы при быстром наборе
- **Перевод запрашивается только для новых слов** (не найденных в базе)
- **Умная логика** - сначала проверка базы, потом автоперевод

### 🆕 Автоматический фокус

- **Фокус на поле ввода** при загрузке страницы
- **Фокус после сохранения** слова/фразы
- **Фокус при смене режима** (слова ↔ фразы)
- **Улучшенный UX** - пользователь сразу может вводить новое слово

### Используемые API перевода:
- **Основной**: LibreTranslate (https://libretranslate.de)
- **Альтернативный**: MyMemory Translation API (https://mymemory.translated.net)

## Технологии

- **Сервер**: Node.js, Express, SQLite3
- **Клиент**: Vue 3 (Options API), Vue Router
- **Стили**: CSS3 с градиентами и анимациями
- **Перевод**: Интеграция с бесплатными API перевода
